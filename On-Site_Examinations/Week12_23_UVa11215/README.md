# UVa 11615 - Family Tree

## 問題描述
在一個擁有 $N$ 代的完美二元家族樹中，每個人都有兩個親生父母。依據題目給定的 Ahnentafel 編號系統，第一代（自己）編號為 $1$，其父親為 $2x$，母親為 $2x+1$。整棵樹共有 $2^N - 1$ 個節點。

然而，我們發現家族樹中的兩位祖先 $A$ 與 $B$ 其實是**同父母的親兄弟**。這意味著：
1. $A$ 與 $B$ 的父親是同一個人、母親也是同一個人。
2. $A$ 與 $B$ 往上的所有祖先網路完全重疊。

給定 $N, A, B$，請計算扣除重複計算的祖先後，整個家族樹中實際上共有多少個「不同的人」。

---

## 邏輯與程式

### 邏輯
1. **精準找出重疊子樹的根節點代數**：
   因為 $A$ 與 $B$ 是親兄弟，他們重疊的是「他們的父母」。在二元樹中，一個節點 $x$ 的父母編號為 $x / 2$。因此，$A$ 與 $B$ 的父母編號即為 $\max(A, B) / 2$（或 $\min(A,B)/2$，因為是親兄弟，其父母節點是同一個）。
2. **利用二元樹結構計算重疊深度**：
   要算出這個父母節點在第幾代，我們可以透過連續除以 $2$ 的次數來推算。知道父母所在的代數 `parent_gen` 後，從這一代一直到最高代（第 $N$ 代）的這整棵子樹，在家族樹中都被重複計算了一次。這棵重疊子樹的層數為 $N - parent_gen + 1$。
3. **高效計算滿二元樹節點數**：
   一棵高度為 $H$ 的滿二元樹，其總節點數為 $2^H - 1$。利用位移運算子 `(1 << H) - 1` 可以在 $O(1)$ 時間內精準求出重疊的祖先人數，最後用總人數 $2^N - 1$ 扣除這整棵重疊子樹的人數即可。

---
### 程式
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 根據 Ahnentafel 編號找出該節點位於第幾代 (1-indexed)
int get_generation(int node) {
    int gen = 0;
    while (node > 0) {
        node /= 2;
        gen++;
    }
    return gen;
}

int main() {
    int t;
    if (cin >> t) {
        while (t--) {
            int n, a, b;
            cin >> n >> a >> b;

            // 完美的 N 代二元樹總人數為 2^n - 1
            int total_people = (1 << n) - 1;

            // A 和 B 是親兄弟，他們的父母是同一個人，編號為 a / 2
            int parent_node = a / 2;

            // 找出父母這個節點在哪一代
            int parent_gen = get_generation(parent_node);

            // 從父母這一代一路上溯到第 n 代，這棵重複子樹的高度為 n - parent_gen + 1
            int overlap_height = n - parent_gen + 1;

            // 重複子樹的總人數
            int overlap_people = (1 << overlap_height) - 1;

            // 實際不同的人數 = 總人數 - 重複人數
            int ans = total_people - overlap_people;

            cout << ans << endl;
        }
    }
    return 0;
}
```
## 複雜度分析

- **時間複雜度**：$O(\log(\max(A, B)))$。主要耗費在 `get_generation` 函數中計算節點代數的 `while` 迴圈。因為題目限制 $N \le 20$，節點編號最大約為 $2^{20}$，迴圈最多跑 20 次，時間複雜度極低，每組測資可在常數時間內完成。
- **空間複雜度**：$O(1)$。僅使用區域變數進行數值運算，不佔用額外記憶體。

## 心得與反思

- **觀察 Ahnentafel 編號系統的規律**：
  這題讓我學到如何將傳統的「家族樹（Family Tree）」與資訊科學中的「滿二元樹（Full Binary Tree）」完美結合。透過題目給出的編號規律，發現「親兄弟的父母編號恰好是 $x / 2$」，進而將複雜的圖形重疊問題，轉化成定位子樹根節點的數學計算。

- **邊界條件與位移安全**：
  雖然這題的 $N \le 20$，使用普通的 `int` 搭配 `1 << n` 不會有溢位的風險，但透過這幾題的練習，我更加體會到在處理樹狀結構的高度與節點數轉換時，使用位移運算子（`<<`）比起 `pow()` 函數更加直觀且高效。
