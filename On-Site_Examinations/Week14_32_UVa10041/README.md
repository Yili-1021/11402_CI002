# UVa 10041 - Vito's Family

## 問題描述
Vito 是個黑手黨教父，他有很多親戚住在紐約的同一條街上（這條街上的門牌號碼都是整數）。Vito 準備搬到這條街上，並希望能選一間房子居住，使得他從自己家出發，去拜訪所有親戚的**總步行距離最短**。

給定這條街上所有親戚的門牌號碼，請計算出 Vito 搬進最優位置後，到所有親戚家的**最小總距離**是多少？（Vito 搬進的房子可以與某位親戚的房子同門牌號碼）。

---

## 解題邏輯與程式

### 核心邏輯
這是一題經典的數學幾何與統計學應用題。假設 Vito 的房子位置在 $X$，親戚們的位置分別為 $S_1, S_2, \dots, S_r$，我們要最小化的目標函數為：
$$\sum_{i=1}^{r} |X - S_i|$$

在數學上，要讓一組數據到某個特定點的「絕對誤差之和」最小，這個特定點 $X$ 最佳的選擇就是這組數據的**中位數（Median）**。

1. **排序找中位數**：讀入所有親戚的門牌號碼後，先將它們由小到大進行排序（`std::sort`）。
2. **定位最佳位置**：
   - 如果親戚人數 $r$ 是奇數，中位數就是正中間的那間房子。
   - 如果親戚人數 $r$ 是偶數，正中間兩個數字之間的任何一個位置（包含這兩點）所算出來的總距離都是一樣的，因此直接取 `r / 2` 處的數值作為教父的家即可。
3. **計算總距離**：確定中位數後，遍歷所有親戚的位置，利用 `abs()` 函數計算出每位親戚到中位數房子的絕對距離，並將其加總即為答案。

### 完整程式碼
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

int main() {
    int t;
    if (cin >> t) {
        while (t--) {
            int r;
            cin >> r;

            vector<int> streets(r);
            for (int i = 0; i < r; i++) {
                cin >> streets[i];
            }

            // 1. 由小到大排序，方便尋找中位數
            sort(streets.begin(), streets.end());

            // 2. 找出中位數作為 Vito 的最佳居住位置
            int vito_house = streets[r / 2];

            // 3. 計算所有人到 Vito 家的絕對距離總和
            int total_distance = 0;
            for (int i = 0; i < r; i++) {
                total_distance += abs(streets[i] - vito_house);
            }

            cout << total_distance << endl;
        }
    }
    return 0;
}
```
## 複雜度分析

- **時間複雜度**：$O(r \log r)$。其中 $r$ 為親戚的人數（$r < 500$）。主要的效能瓶頸在於對親戚門牌號碼進行排序的 `std::sort`，其時間複雜度為 $O(r \log r)$。隨後的距離加總迴圈僅需 $O(r)$。由於 $r$ 非常小，整體程式執行時間接近 0 毫秒。
- **空間複雜度**：$O(r)$。主要消耗在儲存每組測資所有親戚門牌位置的 `std::vector`。

## 心得與反思

- **數學性質取代暴力列舉**：
  這題如果採用暴力法（遞迴或窮舉每個門牌號碼當作起點），時間複雜度會提高到 $O(r^2)$ 甚至是與門牌號碼最大值相關。然而，若能看穿題目的本質是統計學中的「絕對離差和最小化（Least Absolute Deviations）」，直接聯想到「中位數」的數學規律，就能優化成只需要一個簡單的排序與單層迴圈，再次印證了「演算法的盡頭往往是數學」。

- **熟悉 STL 的內建利器**：
  在競賽中不需要自己手寫氣泡排序或快速排序，熟練運用 C++ STL 的 `std::sort()` 可以在平均 $O(r \log r)$ 的時間內穩健完成排序；同時配合 `<cmath>` 中的 `abs()` 函數處理絕對值，能讓整段解題程式碼顯得格外簡潔俐落。
