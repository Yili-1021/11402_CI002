# UVa 10252 - Common Permutation

## 問題描述
給定兩個由小寫英文字母組成的字串 $A$ 與 $B$。請找出一個最長的字串 $x$，使得 $x$ 經過某種重新排列（Permutation）後，可以同時成為 $A$ 的子序列（Subsequence）與 $B$ 的子序列。

如果有多個符合條件的字串 $x$，請輸出**字典序最小（Alphabetical Order）**的那一個。

---

## 解題邏輯與程式

### 核心邏輯
雖然這題的名字有 "Permutation"、敘述中提到 "Subsequence"，看起來很像最長共同子序列（LCS）的變形，但因為**可以任意重新排列且要求字典序最小**，這題本質上是一題非常單純的**字元計數（Counting）**與貪婪問題。

1. **計算字元出現頻率**：我們可以用兩個大小為 26 的整數陣列（或 `std::map`）分別統計字串 $A$ 與字串 $B$ 中每個小寫字母（`a` 到 `z`）出現的次數。
2. **取交集最小值**：對於同一個字母（例如 `a`），如果它在 $A$ 出現了 3 次，在 $B$ 出現了 5 次，那麼它在共同組合中最多只能出現 $\min(3, 5) = 3$ 次。
3. **按字典序輸出**：因為題目要求輸出字典序最小的答案，我們只需要依序從 `a` 到 `z` 檢查這 26 個字母。只要該字母在兩字串中的共同出現次數大於 0，就依序將它印出。從 `a` 檢查到 `z` 的這個順序，自然而然就保障了輸出結果會是字典序最小的。

### 完整程式碼
```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    string a, b;
    // 測資中可能包含空字串，必須使用 getline 讀取整行
    while (getline(cin, a) && getline(cin, b)) {
        vector<int> count_a(26, 0);
        vector<int> count_b(26, 0);

        // 統計字串 A 的字元頻率
        for (char c : a) {
            if (c >= 'a' && c <= 'z') {
                count_a[c - 'a']++;
            }
        }

        // 統計字串 B 的字元頻率
        for (char c : b) {
            if (c >= 'a' && c <= 'z') {
                count_b[c - 'a']++;
            }
        }

        // 依字典序（a 到 z）比對並輸出
        for (int i = 0; i < 26; i++) {
            int common_count = min(count_a[i], count_b[i]);
            for (int j = 0; j < common_count; j++) {
                cout << (char)('a' + i);
            }
        }
        cout << endl;
    }
    return 0;
}
```
## 複雜度分析

- **時間複雜度**：$O(N + M)$。其中 $N$ 和 $M$ 分別為兩個字串的長度。我們只需要各自遍歷一次字串來統計頻率，最後輸出時只跑一個長度為 26 的常數迴圈。相較於 LCS 演算法的 $O(N \times M)$，這種計數法效率極高，執行時間通常為 0 毫秒。
- **空間複雜度**：$O(1)$。我們只需要兩個大小固定為 26 的 `std::vector` 陣列來統計英文字母頻率，所消耗的記憶體空間是固定的常數級別。

## 心得與反思

- **看穿題目的本質與偽裝**：
  這題是一個很好的盲點範例。如果一看到「子序列」就一頭熱地去套用動態規劃（DP）的 LCS 模板，雖然在時間複雜度內可能勉強能過，但除了程式碼冗長之外，還得在最後大費周章地對求出的子序列進行排序。只要冷靜注意到題目說「可以重新排列（Permutation）」，就會發現「位置根本不重要，數量才是重點」，難度瞬間從 DP 降成計數。

- **計數陣列（Bucket/Frequency Array）的妙用**：
  在處理只有特定範圍字元（如 26 個小寫英文字母）的字串問題時，利用 `c - 'a'` 將字元轉換成 `0` 到 `25` 的索引進行統計，是非常經典且高效率的技巧。這不僅省去了使用 `std::map` 的額外開銷，更能完美結合迴圈來自動完成「字典序」的排序要求。
