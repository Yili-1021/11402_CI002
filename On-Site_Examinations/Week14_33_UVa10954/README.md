# UVa 10954 - Add All

## 問題描述
給定 $N$ 個正整數，我們想把這些數字全部加總成一個數字。每次相加時，你只能選擇其中兩個數字進行加總，而這兩個數字相加的結果，就是該次運算的**成本（Cost）**。

因為加總的順序不同，所產生的累積總成本也會截然不同。請找出一個最優的加總順序，使得將這 $N$ 個數字完全合併成一個數字時的**總成本（Total Cost）達到最小**。

---

## 解題邏輯與程式

### 核心邏輯
這是一題非常經典的**貪婪演算法（Greedy Algorithm）**與**優先佇列（Priority Queue）**的結合應用，其基本思維與霍夫曼編碼（Huffman Coding）的建樹過程完全相同。

1. **貪婪策略**：為了讓最後累積的總成本最小，我們每次進行相加時，**都必須挑選當前所有數字中最小的兩個數字**。因為越早被加總的數字，其數值在後續的合併中會被重複計算越多次。讓越小的數字被重複計算，才能保障總成本最低。
2. **優先佇列的引入**：在每次將最小的兩個數字取出並相加後，其「和」會變成一個全新的數字，必須重新放回數字堆中，供下一輪挑選。如果每次放回都重新使用 `std::sort` 排序，會導致嚴重的超時（TLE）。
3. **最小堆疊（Min-Heap）**：我們可以使用 C++ STL 的 `std::priority_queue` 並設定為最小堆疊。這樣不論是「取出最小值 $O(\log N)$」還是「插入新元素 $O(\log N)$」，都能在極短的時間內完成。



### 完整程式碼
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    while (cin >> n && n != 0) {
        // 建立一個最小堆疊 (Min-Heap)
        priority_queue<int, vector<int>, greater<int>> pq;

        for (int i = 0; i < n; i++) {
            int val;
            cin >> val;
            pq.push(val);
        }

        long long total_cost = 0;

        // 當佇列中剩下一顆以上的數字時，持續進行合併
        while (pq.size() > 1) {
            // 取出當前最小的兩個數字
            int first = pq.top(); pq.pop();
            int second = pq.top(); pq.pop();

            int cost = first + second;
            total_cost += cost; // 累積本次合併的成本

            // 將合併後的新數字放回佇列中
            pq.push(cost);
        }

        cout << total_cost << endl;
    }
    return 0;
}
```
## 複雜度分析

- **時間複雜度**：$O(N \log N)$。將 $N$ 個元素推入優先佇列需要 $O(N \log N)$。接著在 `while` 迴圈中，每次合併會取出兩個元素並塞回一個元素，一共需要進行 $N-1$ 次合併。每次對 Min-Heap 的操作都是 $O(\log N)$，因此總時間複雜度為 $O(N \log N)$。對於題目上限 $N \le 5000$，運算量極小，可在幾毫秒內執行完畢。
- **空間複雜度**：$O(N)$。主要消耗在優先佇列（Priority Queue）中同時儲存的元素個數，最多為 $N$ 個數字。

## 心得與反思

- **動態排序的最佳化利器**：
  這題讓我深刻體會到「靜態排序」與「動態維護排序」的差異。如果一組資料在運算過程中會不斷有新元素加入、舊元素離開，且我們隨時都需要知道極值（最大或最小），那麼 `std::priority_queue` 絕對是比重複呼叫 `std::sort` 更優雅且高效數百倍的選擇。

- **精準的貪婪證明**：
  剛看到題目時，或許會想直接由小到大依序累加（像是陣列排序後從頭加到尾）。但仔細思考會發現，隨著新產生的「和」越來越大，它有可能會超越陣列後方的其他數字。這題強迫我們必須在每一步都重新精算，落實了「每一步都選擇當下局部最優解」的貪婪精神。
