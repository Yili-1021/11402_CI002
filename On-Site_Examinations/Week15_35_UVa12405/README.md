# UVa 12405 - Scarecrow

## 問題描述
有一片大小為 $1 \times N$ 的農田，農田中有些格子是肥沃的土地（以字元 `.` 表示），有些格子則是貧瘠的荒地（以字元 `#` 表示）。

為了保護肥沃土地上的作物不被鳥類破壞，你需要在農田中放置稻草人。每個稻草人一旦被放置在某個格子（不論該格子是 `.` 還是 `#`），都可以同時保護**它本身、左邊鄰居、以及右邊鄰居**（即連續 3 個格子）。

請計算出最少需要放置幾個稻草人，才能讓所有肥沃的土地（`.`）都受到保護？

---

## 解題邏輯與程式

### 核心邏輯
這題可以用非常直觀且有效率的**貪婪演算法（Greedy Algorithm）**來解決。我們的策略是由左向右依序掃描農田：

1. **遇到荒地（`#`）**：因為荒地不需要被保護，我們可以直接跳過它，不作任何處理。
2. **遇到肥沃土地（`.`）**：這是整個貪婪策略的精髓。為了讓這個稻草人的防守效益最大化，我們**不應該**把稻草人放在當前這個 `.` 的左邊（因為左邊已經處理完了），也**不應該**直接放在當前這個 `.` 的位置。最聰明的做法是把稻草人放在它的**右邊那格（$i+1$）**。
3. **稻草人防守範圍覆蓋**：當我們把稻草人放在 $i+1$ 的位置時，它會同時保護 $i$、$i+1$、$i+2$ 這連續 3 格。因此，不論 $i+1$ 和 $i+2$ 原本是 `.` 還是 `#`，它們都已經被強制納入保護範圍內了。接下來我們可以直接將指針向右跳 3 格（即 `i += 3`），繼續處理後續未被覆蓋的土地。

透過這種「只要看到破綻（`.`），就往右跨一格放稻草人，並一口氣推進 3 格」的貪婪思維，保證能得到全域最少稻草人的最優解。

### 完整程式碼
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int t, case_num = 1;
    if (cin >> t) {
        while (t--) {
            int n;
            string field;
            cin >> n >> field;

            int scarecrows = 0;
            for (int i = 0; i < n; ) {
                if (field[i] == '.') {
                    // 遇到需要保護的土地，貪婪地將稻草人放在 i+1 的位置
                    scarecrows++;
                    // 稻草人可以覆蓋 i, i+1, i+2，所以指針直接往後跳 3 格
                    i += 3;
                } else {
                    // 遇到不需要保護的荒地，直接看下一格
                    i++;
                }
            }

            cout << "Case " << case_num++ << ": " << scarecrows << endl;
        }
    }
    return 0;
}
```
## 複雜度分析

- **時間複雜度**：$O(N)$。不論農田的分布如何，我們只需要用一個指針從頭到尾遍歷一次長度為 $N$ 的字串。每個字元最多只會被存取一次，因此時間複雜度是極其優秀的線性時間 $O(N)$，可在 0 毫秒內輕鬆通過。
- **空間複雜度**：$O(N)$。主要消耗在儲存代表農田結構的 `std::string` 字串空間，記憶體耗費微乎其微。

## 心得與反思

- **貪婪決策的無後效性**：
  剛看到這題時，可能會想說要不要用動態規劃（DP）去精算每一格放或不放的各種組合。但冷靜分析後會發現，當我們由左往右走時，最左邊那個尚未被保護的 `.` 勢必要有人來照顧它。而能照顧它的最佳解，絕對是把稻草人往右放一格（發揮最大向右延伸的覆蓋力），這個局部選擇完全不會對後面產生更壞的影響，完美符合貪婪演算法的特性。

- **指針動態步長跳躍（步進控制）**：
  這題在寫 `for` 迴圈時，不需要像傳統題目一樣習慣性地在小括號尾端寫 `i++`。靈活地在迴圈內部根據條件進行 `i += 3` 或 `i++` 的動態步長跳躍，可以讓程式碼完全貼合「放了稻草人就推進 3 格」的邏輯，既不容易寫錯，程式碼讀起來也非常優雅直觀。
